# Header font comparison

Full current homepage preview with only the brand typeface changed:
Satoshi Light 300, General Sans Light 300, Instrument Sans Regular 400,
and the current Montserrat Light 300 for comparison. Desktop 27px / mobile 25px.

Local font copies downloaded from the official Fontshare CSS endpoint (Satoshi,
General Sans) and google/fonts (Instrument Sans, OFL included).

- https://www.fontshare.com/fonts/satoshi
- https://www.fontshare.com/fonts/general-sans
- https://github.com/Instrument/instrument-sans

The preview snapshots the current Astro build, removes analytics, and uses the
existing portrait modules. It does not modify the production pages.

Serve the repository root and visit:
http://localhost:60961/prototypes/header-fonts/
