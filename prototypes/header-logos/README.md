# Header logo studies

Three isolated HTML mockups for Maxime de Visscher's personal site:

- `editorial.html`: serif wordmark with a copper punctuation mark.
- `geometric.html`: custom vector M alongside the complete name.
- `expressive.html`: expressive first name, full surname and small accent star.

Open `index.html` through a server running at the repository root. The comparison
board switches between the three headers and desktop / 390px mobile previews.
The portrait is static to focus the comparison on the header. Navigation links
are placeholders. Production files are not modified by these studies.

```sh
python3 -m http.server 60961 --bind 127.0.0.1
```

http://localhost:60961/prototypes/header-logos/
