# Header signatures — exploration 03

User feedback: earlier typography studies were too classic and disconnected from
the approved copper particle portrait website. Keep the identity understated and
confident, with the complete name visible, but explore original letter construction.

- Facettes: diagonal cuts in M / V and a copper fragment in x.
- Jonction: x–i connection with a corresponding diagonal in V.
- Émergence: first m assembled from three modules, then solid letterforms.

Generated using the built-in image_gen tool. Exact original briefs are saved in
prompts.json. A second edit pass removed unwanted lighting effects.

These PNGs are concept mockups, not production vector logos. Small-scale optical
adjustments and vector reconstruction remain for a selected direction.
