## Development

The project uses Astro 7 and pins Node.js and pnpm through Volta.

* `pnpm install`
* `pnpm dev`
* `pnpm check`
* `pnpm build`

## Tools used

* **Framework**: [Astro](https://astro.build/)
* **Package manager**: [pnpm](https://pnpm.io/)
* **Styling and motion**: native CSS
